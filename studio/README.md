# Studio — memoria del juego

Aquí se guarda lo que hablamos. El chat no es el archivo; esta carpeta sí.

Después de cada plática de diseño, el agente **actualiza** estos archivos.
Antes de programar una feature, el agente **los lee**.

| Archivo | Qué guarda |
|---|---|
| `story.md` | Premisa, mundo, personaje, tono |
| `mechanics.md` | Cómo se juega, loop, controles |
| `diseno-mundo.md` | El mundo completo: pueblos, rutas, piedras, economía simulada, alijos |
| `art.md` | Qué se genera en código, qué se importa |
| `decisions.md` | Decisiones fechadas (sí / no / pendiente) |
| `sessions/` | Bitácora de cada conversación |

La guía visual (pestañas) está en `docs/guides/stones-studio.html`.

El molde para **otro** juego no es este repo: `~/Development/framework-ia-videojuegos`
y el skill personal `empezar-juego`.

Assets de prueba: `public/assets/proto/`.
Assets cerrados: `public/assets/final/`.
Pixel art hecho en código: `src/art/` (revisar en `lab.html`).
